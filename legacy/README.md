# 기존 장애 진단 실습 코드

`incident_agent/`에 제공 ZIP의 원본 코드·샘플 데이터를 보존합니다. 신규 식품 서비스는 이 코드를 import하거나 기본 실행 경로로 사용하지 않습니다. 새 실행 방법과 재사용 관계는 루트 `readmd.md`를 확인하세요. 별도 실습 실행 시 해당 폴더 안에서 독립 가상환경과 설정을 준비해야 합니다.

기존 장애 진단 UI의 대용량 스크린샷과 설명 자료는 신규 서비스 저장소에서 제외합니다. 원본 ZIP과 기존 작업 폴더에는 보존되어 있습니다. 신규 식품 서비스의 화면은 `doc/food-agent/screenshots/`에 있습니다.
