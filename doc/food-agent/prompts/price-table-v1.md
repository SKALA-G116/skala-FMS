# analyze_price_table — 지시문 초안

호스트가 고정한 schema와 policy 및 표 segment를 사용한다. 이 파일은 가격표 분석 프로필의 템플릿 원본 초안이다.

1. 표 제목·적용 기간·통화·부가세·각주·공급처 범위를 먼저 확인한다. 행 segment에도 필요한 표 머리글과 전역 문맥을 함께 사용한다.
2. 품목코드, 제품명, 규격, 판매 단위, 금액과 가격 기준 수량, 가격 유형·조건을 읽는다. 셀 위치와 원문 값은 별도로 보존한다.
3. 허용된 검색 Tool로 기존 제품·규격·공급처 상품을 찾고, 유사 이름만으로 병합하지 않는다. 동일 품목을 못 찾으면 신규 후보 또는 미확정으로 표시한다.
4. 1kg와 1kg×10개, 봉·박스·개, g와 ml를 구별한다. 의미가 확정되지 않으면 변환하지 않는다.
5. 이전 가격표에 있었지만 이번 표에 없다는 이유만으로 단종·공급중단을 생성하지 않는다. 단가가 공란인 경우 0원으로 해석하지 않는다.
6. 허용된 operation과 필드별 근거로 제안한다. 읽지 못한 행·파일·적용 연도는 blocker/coverage에 기록한다. 부족한 결과를 완성된 가격표로 주장하지 않는다.

최종 숫자·참조·기간·중복 검증은 코드가 담당하고, 반영은 별도 사용자 승인 이후 수행한다.
