# OCR 위치와 상품별 근거 보존

## 이번 변경

기존 처리는 영역 분류 시 문장 앞16자(예산에 따라4자까지)만 보여 주고, 상품 영역을 정한 뒤에는 문장들을 하나의 문자열로 합쳤습니다. 이 과정에서 이후 정보 추출에 필요한 개별 좌표가 사라졌습니다.

이제 OCR 문장의 전체 텍스트와 좌표를 영역 분류에 전달하고, 추출 단계에서도 문장 ID·정규화 좌표·상품/공통 안내 소속을 유지합니다. 페이지·시트 위치는 묶음에 한 번 전달해 같은 메타데이터의 반복을 줄입니다.

1. **상품 영역 판단:** 전체 문장과 좌표를 보고 판단합니다. 상품 전용 문장은 다른 상품의 공통 안내로 공유하지 못하게 검증합니다. 엑셀의 명확한 이미지-행 연결은 기존처럼 우선 사용합니다.
2. **역할 보존:** 상품 전용 문장과 공통 안내를 구분합니다. 이 역할은 checkpoint 재개에도 유지합니다. 이전 checkpoint는 저장된 영역 판단에서 복구하며 소속을 확인할 수 없으면 공통 안내로 제한합니다.
3. **필드 근거:** 이미지 응답에 선택 필드 `field_evidence`를 추가합니다. 원재료·알레르기·가격 등의 근거 ID를 검증하고, 생략된 경우 원문 일치로 지원 문장을 찾습니다. 다른 영역 ID나 공통 안내만으로 상품 속성을 채운 값은 제외하고 원문 검수로 남깁니다.
4. **출처 저장:** 표준 식품 DTO의 `field_sources`에 필드별 근거 ID와 원본 좌표를 보관합니다. 상품 영역 전체 근거도 별도로 유지합니다. 적용일·사유의 추가 근거 검색도 해당 이미지 상품 그룹 안으로 제한합니다.
5. **검수:** 원문 패널의 ‘근거 보기’에서 원재료·알레르기·규격 등을 선택해 연결된 문장/위치를 확인합니다. 해당 상품의 전체 근거 밖에 있는 ID는 표시하지 않습니다.

## 자원 한도와 한계

추가 모델 호출·추가 모델 설치는 없습니다. 이미지 입력에만 필드 근거 스키마를 추가합니다. 좌표를 보존하기 위해 입력이 커질 수 있으므로 기존 전체 모델 입력 한도, 영역 본문4000바이트·페이지 레이아웃6500바이트 한도를 유지합니다. 예산을 넘으면 의미를 잘라 추론하지 않고 원문 검수로 보냅니다. 따라서 복잡한 페이지는 이전보다 자동 처리 범위가 줄 수 있습니다.

OCR가 잘못 읽은 글자나 처음부터 잘못 나눈 영역을 모두 교정하는 것은 아닙니다. 새 레이아웃 검출 모델·자동 영역 확대 재OCR·멀티모달 모델 재검증은 이번 변경에 포함하지 않았습니다. 실제 업체별 필드 정확도와 상품 간 혼입률을 측정해야 합니다.

과거에 완료된 분석을 자동 수정하지 않습니다. 수정된 근거 연결을 얻으려면 새 분석이 필요합니다. 승인된 식품·단가를 자동 덮어쓰지 않습니다.

## 검증

- 16자 뒤에 있는 상품 구분 정보 보존 및 입력 예산 초과 시 무손실 검수 전환.
- 근접한 두 상품의 전용 문장을 공통 안내로 재사용하는 응답 차단.
- 공통 알레르기 범례를 상품 함유 표시로 사용하는 응답 제외.
- 여러 줄로 나뉜 원재료의 근거 ID·좌표 유지.
- 다른 상품 영역의 ID를 참조하는 필드 제외.
- 새 checkpoint의 역할 유지 및 과거 checkpoint의 저장된 판단으로 역할 복구.
- 검수 화면에서 필드별 근거 선택 시 현재 상품에 속한 ID만 노출.

검증은 합성 OCR·모의 LLM과 격리 DB의 회귀 테스트입니다. 실제 추출 정확도나 시간 절감률을 측정한 결과가 아닙니다. 전체 테스트 결과는 요구사항 점검 문서에 기록합니다.

전체 백엔드179개·프론트엔드18개 테스트와 Vite 빌드 통과(2026-10-22). worker를 정상 종료·재시작해 저장된 작업이 재개되는 것을 확인했습니다. 이전에 완료한 구간의 추출값을 새 결과로 덮어쓰지는 않았습니다.
