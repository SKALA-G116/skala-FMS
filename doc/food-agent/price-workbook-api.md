# 원본 단가표 조회 확장

원본 Excel의 시트·열·행을 보존해 사람이 바로 비교하고 필터링하는 기능입니다. 원본 조회 등록은 승인된 상품·가격 사실 생성과 독립적입니다. 기존 `openapi.json` v0.2 설계 계약에 아래 확장이 추가됩니다.

## 화면

`/prices`의 기본 탭은 **원본 단가표**, 다른 탭은 **승인된 DB 단가**입니다. 파일 선택 → 시트 선택 → 전체 검색 또는 열 조건 추가 → 필터 적용 순서입니다. 열 제목으로 정렬하고, 행을 클릭하면 모든 열과 원본 좌표를 확인합니다. 25/50/100행씩 조회하며 가로 스크롤·열 숨기기를 지원합니다.

열 조건은 AND로 결합됩니다. 문자 포함·정확히 일치·빈 셀·값 있음, 숫자 이상/이하/일치를 지원합니다. 필터·정렬·페이지 이동은 PostgreSQL에서 처리하고 브라우저에 전체 파일을 보내지 않습니다. 0과 빈 셀을 구분하며 코드의 앞자리 0을 보존합니다. 중복되거나 없는 헤더도 A/B/C 열 키로 구분합니다. 제목 없는 열을 삭제하거나 원본 메모를 명령으로 실행하지 않습니다.

## API

모두 기존 세션 인증을 사용합니다. 쓰기는 admin/operator + CSRF + Idempotency-Key가 필요하며 reader/reviewer도 조회할 수 있습니다.

| 방식 | 경로 | 의미 |
|---|---|---|
| GET | `/api/v1/price-workbooks` | 등록 파일 목록 (최근 100개) |
| POST | `/api/v1/price-workbooks/import` | multipart `file`, `title`로 XLSX와 원문 문서 등록 |
| POST | `/api/v1/price-workbooks` | `{"document_revision_id":"uuid"}`로 이미 등록한 문서의 XLSX 연결. 같은 revision은 같은 workbook 반환 |
| GET | `/api/v1/price-workbooks/{id}` | 시트별 열·원본 헤더·행 수·문서 revision·파일 hash |
| GET | `/api/v1/price-sheets/{id}/rows` | 검색·필터·정렬·페이지 조회 |

행 조회 쿼리:

- `q`: 전체 셀에서 문자 포함 검색, 최대 500자
- `filters`: JSON 배열, 최대 20개. 예: `[{"column":"B","op":"contains","value":"간장"},{"column":"I","op":"gte","value":"20000"}]`
- `op`: `contains`, `equals`, `empty`, `not_empty`, `gte`, `lte`, `eq_number`
- `sort`: `row_number` 또는 메타데이터의 열 키. `direction`: asc/desc. 같은 값은 원본 행 번호로 정렬
- `offset`: 0 이상. `limit`: 1~100, 기본 50
- 응답: `items:[{row_number,cells,cell_range}], total,sheet_row_count,offset,limit,has_more`

숫자 필터·정렬은 별도 numeric JSON 값과 PostgreSQL numeric을 사용합니다. SQL 열/정렬 토큰은 서버가 생성한 열 키와 enum만 허용하며 필터 값은 바인딩합니다. 문자 검색의 `%`, `_`는 와일드카드로 해석하지 않습니다. 시트 데이터는 등록 후 불변이므로 offset 페이지 중간에 행이 추가되는 문제를 피합니다.

## 저장·처리 한계

`002_price_workbooks.sql`에 파일 메타데이터, 시트, 행 테이블을 추가했습니다. 파일은 기존 hash 저장소에 보관합니다. 행 JSON은 원본 문자열과 숫자 값을 따로 저장합니다. 셀 하나 최대 32,768자, 파일당 비어 있지 않은 셀 20만 개, 파일 25MiB, 시트 20개, 시트당 데이터 2만 행·100열, 압축 해제 100MiB가 상한입니다. 위반 시 오류와 DB 롤백으로 처리합니다.

XLSX의 첫 행을 헤더로 사용합니다. 원본 열 너비·색·셀 병합·도형을 재현하는 Excel 편집기는 아닙니다. 수식은 저장된 계산 결과를 보여주며, 결과 캐시가 없으면 수식과 ‘저장된 결과 없음’을 표시합니다. 계산·매크로·외부 링크를 실행하지 않습니다. XLS는 기존 텍스트 추출 경로를 지원하지만 이 원본 표 화면은 XLSX 전용입니다.

향후 데이터가 커지면 선택도가 높은 업체군·코드·가격 열을 정규 컬럼으로 매핑하거나 검색 인덱스를 추가합니다. 현 단계에서는 전체 행을 매 요청에 Python/브라우저 메모리로 읽는 구조를 사용하지 않습니다.

## 챗봇 판단

현재 필수 기능은 정확한 표 조회, 근거 검토, 승인입니다. 대화 UI가 없어도 수집·분석 Agent는 작업자로 실행됩니다. 별도 챗봇은 구현하지 않았습니다.

추후 ‘지난달보다 가격이 오른 품목’, ‘이 품목의 중단 사유와 대체품’ 같은 자연어 조회 수요가 검증되면 읽기 전용 도구를 사용하는 보조 기능으로 추가합니다. 사용자 질문 → 허용된 필터/조회 계획 → 권한 있는 API → 표 결과·기준일·근거를 반환하는 구조입니다. 자연어로 승인·삭제·직접 DB 쓰기를 허용하지 않습니다. 현재 파일 두 시트를 서로 다른 월로 가정하지 않으며, 월간 비교는 기준월 매핑과 상품 일치 규칙이 먼저 필요합니다.
