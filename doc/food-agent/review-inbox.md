# 검수함의 표시 단위

검수함은 자료별 최신 완료 분석을 한 행으로 표시합니다. 분석 결과가 없는 수동 변경안은 별도로 유지합니다. 내부 승인·반영 배치를 합치거나 삭제하지 않습니다.

기존 `AI 변경안 1/2/3`은 한 분석의 DB 작업 묶음이었습니다. 변경안당 50개 작업 제한 때문에 생성·규격·기준정보·공급 품목·단가 작업이 여러 묶음으로 나뉩니다. 이 숫자는 식품 수나 AI 호출 수가 아닙니다.

`GET /api/v1/review-inbox`는 큰 원문·모델 로그를 읽지 않고 DB에서 제목·상태·검토 항목 수만 투영합니다. 같은 자료의 최신 완료 분석을 먼저 선택하고 검색·상태 필터·페이지를 적용합니다. 삭제 보관한 자료는 제외합니다. 완료 분석에 내부 변경안이 없어도 검수함에 나타납니다.

- 검토 항목: 분석 보고서의 추출 후보 수입니다. 정확한 식품 수를 의미하지 않습니다.
- 검토 대기: 전체 후보에서 확인·제외한 후보를 뺀 수입니다.
- 수동 변경안: DB 작업 수로 표시하고 품목 수와 구별합니다.
- 승인·반영 상태: 내부 묶음들의 상태를 집계하되 일부만 승인됐을 때 전체 승인으로 표시하지 않습니다.
- 이전 분석과 승인 이력은 기존 상세·식품 이력에 보존됩니다.

회귀 검증: 세 내부 배치가 한 행으로 나타나는지, 검토 수 집계, 최신 결과 선택, 그룹 단위 페이지 적용, 내부 배치 보존 및 삭제 자료 제외를 테스트합니다. 이 변경은 검수함의 표시 단위를 고친 것으로 OCR/추출 정확도 개선을 의미하지 않습니다.
