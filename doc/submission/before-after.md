# 트러블슈팅 Before / After

README 5절에서 연결되는 문제 해결 근거입니다. 발표에서는 01의 행 보존 사례와 [원재료 누락 수정](../food-agent/ingredient-extraction.md)을 45초 동안 설명하고, 05의 라벨 응답 오류 사례와 나머지는 질의응답용으로 사용합니다. **동일 입력 실측 비교, 실제 실행 관찰, 테스트 대역 검증을 구분**합니다.

| 사례 | 문제 → 수정 | 결과 근거 |
|---|---|---|
| [01. 표 행·맛·가격 보존](before-after/01-table-preservation.md) | 다른 맛을 중복으로 합침 → 병합 셀·맛·가격 기준 보존 | 동일 XLSX의 검토 행 8→18, 가격 값 9→19 |
| [02. OCR 수명 관리](before-after/02-ocr-lifecycle.md) | native 충돌 보고 → 정상 종료·CPU 제한·복구 가능한 오류 | 실제 합성 이미지 두 사이클 exit 0 |
| [03. 승인 계약 불일치](before-after/03-review-contract.md) | 근거가 많으면 승인 실패 → 생성·승인 스키마 상한 통일 | 41개 근거 승인·반영·감사 보존 통합 테스트 |
| [04. XLSX 라벨 이미지](before-after/04-embedded-labels.md) | 셀만 읽음 → OCR+행 연결+빈 속성 보완 | 합성 파일·모의 모델 회귀 테스트 |

[05. 모델 형식 오류와 구간별 복구](before-after/05-model-schema-recovery.md)에는 같은 입력의 실제 오류 재현과 전용 라벨 응답 검증을 추가했습니다.

2026-10-22 마지막 코드 검증은 Backend159/Frontend16, Vite 빌드 통과입니다. 이후 이번 README 중심 발표 변경은 문서 편집이며 프로그램 기능을 바꾸지 않습니다.

## 실측으로 설명할 수 있는 것

[동일 파일 재실행 JSON](table-preservation-benchmark.json)은 입력 SHA-256, Before `13e4847`, After `5a8ff51`, 행별 결과를 보존합니다. DTO helper는 현재 코드를 공유하며 DB·모델·네트워크는 제외한 회귀 비교입니다. 전체 과거 환경의 A/B 실험이 아닙니다.

[실제 Agent 실행 JSON](table-demo-result.json)은 별도 실제 실행의 도구 선택 1회와 6.027초를 보존합니다. 이는 Before/After 속도 비교가 아닙니다. 현재 DB에는 해당 과거 run이 없어 보존한 JSON·캡처로 공유합니다.

![동일 입력 비교 캡처](screenshots/09-before-after.jpg)

## 아직 수치로 설명할 수 없는 것

전체 정확도·검색 정확도·시간 절감률·모델 비용 절감률·Retry 감소율·시스템 전체 메모리 절감률은 측정하지 않았습니다. 회귀 테스트나 합성 이미지의 정상 종료 결과로 이를 대신하지 않습니다. 실제 라벨의 OCR 정답률과 운영자의 검토 시간은 별도 정답셋·현장 검증이 필요합니다.
