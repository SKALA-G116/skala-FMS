# 배경 근거: 광주 초·중·고 규모와 업무 병목

확인일: **2026-10-22, Asia/Seoul**. 발표에서는 기준 시점이 명확한 공개자료의 설명을 인용하며 이를 2026년 현재 학교 수의 전수 검증이라고 소개하지 않습니다.

## 학교 수의 근거와 계산

[공공데이터포털 학교검색 파일데이터](https://www.data.go.kr/data/15151786/fileData.do)의 상세 설명은 광주광역시교육청 누리집 학교검색 자료라고 밝히고 데이터 기준일을 **2025-11-09**로 명시합니다.

| 학교급 | 공개자료 설명에 기재된 수 |
|---|---:|
| 초등학교 | 155개 |
| 중학교 | 91개 |
| 고등학교 | 68개 |
| 세 학교급 합계 | **314개** |

합계는 155+91+68로 직접 계산했습니다. 유치원·특수학교·고등기술학교·각종학교는 이 합계에서 제외했습니다. 공개 페이지의 학교급별 설명을 사용했으며 CSV 원본을 내려받아 분교·폐교·중복을 재집계한 수는 아닙니다. 같은 페이지의 전체 행 수 메타데이터와 설명상의 전체 학교 수는 일치하지 않아 전체 행 수를 학교 수로 대신 사용하지 않았습니다.

## 어디까지 사실이고 어디부터 서비스 설계의 해석인가

- **공개자료의 사실:** 기준일과 세 학교급의 설명상 수치.
- **사용자 제공 업무 배경:** 학교 영양 업무에서 단가표를 참고하고 업체별 양식·공급 중단·대체품 공지를 확인한다는 설명.
- **프로젝트의 해석:** 같은 변경 공지를 기관마다 확인한다면 탐색·해석·장부 대조가 지역 규모로 반복될 수 있다는 병목 구조.
- **미측정:** 실제 참여 학교·영양 담당자·급식 운영 학교 수, 한 공지를 확인한 담당자 수, 처리 시간·절감률·누락 사고 빈도.

발표에서는 “314개 학교가 사용한다”, “314명의 업무를 대체한다”, “몇 시간 절감했다”라고 말하지 않습니다. 도입 효과는 향후 업무 관찰·사용자 인터뷰·검토 시간 비교로 평가합니다.

## 45초 도입 문장

“광주 학교검색 공개자료의 2025년11월 기준 설명에는 초등155개, 중학교91개, 고등학교68개, 합계314개교가 있습니다. 학교의 영양 업무에서는 식단에 쓸 제품과 단가뿐 아니라 지금도 공급되는지 확인해야 합니다. 그런데 변경은 업체별 게시글과 이미지, 엑셀로 흩어져 옵니다. 같은 공지를 학교마다 다시 읽고 장부와 대조한다면 이 확인 작업이 지역 전체에서 반복될 수 있습니다. 식품장부는 자료 정리를 Agent가 맡고, 담당자는 근거를 보고 승인하는 CMS로 이 병목을 줄이려는 프로젝트입니다.”
